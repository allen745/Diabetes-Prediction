# Diabetes-Prediction

# Diabetes Prediction Model
This project uses a Support Vector Machine (SVM) to predict whether a person has diabetes based on their medical attributes.

**Dependencies**:-

pandas for data manipulation and analysis
numpy for numerical computations
sklearn for machine learning algorithms and utilities

 **Data**:-
The dataset used in this project is the Diabetes Dataset from Kaggle, which contains 768 records of patients with 9 attributes each.

**Model**:-

**Data Preprocessing**:-

Load the dataset into a pandas DataFrame
Check for missing values
Standardize the data using StandardScaler from sklearn.preprocessing

**Model Selection**:-

Train a Support Vector Machine (SVM) classifier with a linear kernel

**Model Evaluation**:-

Split the data into training and testing sets
Calculate the accuracy of the model on both training and testing sets

**Prediction**:-

Create a function to predict whether a person has diabetes based on their medical attributes

**Code Structure**:-
The code is divided into the following sections:

Data Collection and Analysis: Load the dataset, check for missing values, and standardize the data.
Model Training: Train an SVM classifier on the standardized data.
Model Evaluation: Calculate the accuracy of the model on both training and testing sets.
Prediction System: Create a function to predict whether a person has diabetes based on their medical attributes.

**Example Use Cases**:-
**Training the Model**:-

Run the code to train the model on the dataset.
**Making Predictions**:-

Use the prediction function to predict whether a person has diabetes based on their medical attributes.

**Installation and Running**:-

To run the code, follow these steps:

Install the required dependencies using pip install pandas numpy scikit-learn.
Clone the repository or download the code.
Run the code using python diabetes_prediction.py.

# Note
This code serves as a starting point for exploring diabetes prediction using machine learning. The accuracy of the model may vary depending on the dataset and the specific attributes used.
